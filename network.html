Run the Site Locally

  1. Open the project folder in Visual Studio Code.
  2. Install the Live Preview extension from Microsoft.
  3. Open network.html and select Show Preview.
  4. The page opens at http://127.0.0.1:3000/network.html and reports "Local network recognized."

The public copy of the store runs on GitHub Pages over HTTPS, so this page reports "Live on the public web" there.
